# Computer Science 1 / Spring 2025

This repo is a collection of my C++ programming assignments from my CSCI 1 class.

## Assignments

### Module 2
- [Q1 — Square a number](assignments/module-02/Q1/main1.cpp) - Asks the user for a number and prints its square.
- [Q2 — Item total](assignments/module-02/Q2/main2.cpp) - Takes the names and prices of three items and calculates their total cost.
- [Q3 — Division and remainder](assignments/module-02/Q3/main.cpp) - Divides two user-provided integers and displays the quotient and remainder.

### Module 3
- [Input and characters](assignments/module-03/Module3/main1.cpp) - Practices reading an integer and a character from the user.
- [Strings and user input](assignments/module-03/Module3/main2.cpp) - Asks for a name and hometown, then prints them back to the user.
- [Sales tax and formatting](assignments/module-03/Module3/main3.cpp) - Calculates sales tax on two items and displays a formatted total.
- [Random numbers](assignments/module-03/Module3/main4.cpp) - Generates random numbers, including a dice roll and a number within a range.
- [Switch statement exercise](assignments/module-03/Module3/main.cpp) - Uses a switch statement to change a total based on an entered number.
- [Switch statement (alternate)](assignments/module-03/Module3/main15.cpp) - An alternate version of the switch statement exercise.

### Module 5
- [Counting by fours](assignments/module-05/Module5/main1.cpp) - Uses a loop to print multiples of four from 0 to 120.
- [Restaurant ordering system](assignments/module-05/Module5/main2.cpp) - Lets the user order food from a menu and prints an itemized bill.
- [ASCII pattern](assignments/module-05/Module5/main.cpp) - Uses nested loops to draw a pattern of hash symbols based on an odd-numbered size.

### Module 6
- [Candle drawing](assignments/module-06/Module%206/main.cpp) - Uses functions to ask for sizes and print a simple candle-like ASCII drawing.

### Module 9
- [Letter grades and GPA](assignments/module-09/Module9/main.cpp) - Stores five letter grades in an array and calculates a GPA value.

### Module 10
- [Sorting and searching](assignments/module-10/Module%2010/main.cpp) - Sorts an array of characters and starts a search feature; the search function is unfinished.

### Module 12
- [Phone number validation](assignments/module-12/Module%2012%20Assignment/main.cpp) - Checks a phone number string for digits and dashes in the expected positions.

### Module 13
- [Pet structure](assignments/module-13/Module%2013/main.cpp) - Introduces C++ structs by creating a Pet and assigning a name to it.

## Additional Projects

- [Movie Rating](projects/movie-rating/MovieRating/main.cpp) - Asks the user to rate three movies, chooses a favorite based on those ratings, and calculates their average.
